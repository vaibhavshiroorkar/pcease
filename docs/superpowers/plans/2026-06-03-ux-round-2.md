# UX Round 2 - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Refine Browse, rework Compare into one unified table, simplify Builder share, turn Guide into a section switcher, reflow the Footer, and restructure Advisor to a left-selectors / right-build layout.

**Architecture:** Frontend-only. Each area is an independent, separately-committed task. Reworks reuse existing markup where possible (Compare promotes its table view; Advisor reuses the build-rendering blocks).

**Tech Stack:** React 18, Vite, vitest (node env), react-icons, plain CSS tokens.

## Task 1: Browse refinements

**Files:** `frontend/src/components/SpecTable.jsx`, `frontend/src/pages/Browse.jsx`, `frontend/src/pages/Browse.css`, `frontend/src/components/SpecTable.css`

- [ ] **Remove Savings column** from `SpecTable`: delete the `Savings` `<SortHead>` and the `st-td--save` cell + the `saveOf`/`getSavings` usage there.
- [ ] **Remove the "Pick a category to compare specs." hint** (`st-hint` block) from `SpecTable`.
- [ ] **Keep grid/list toggle visible but disabled in Advanced** (Browse.jsx): instead of `mode === 'simple' && (...)` around `br-view-toggle`, always render it; add `disabled` + an `is-disabled` class to its buttons when `mode === 'advanced'`. Add CSS so disabled toggle is greyed.
- [ ] **Unified filter sidebar** (Browse.jsx + Browse.css): replace the inline `br-advanced-filters` panel with a collapsible left sidebar (`br-filter-sidebar`) toggled by the existing Filters button. It holds brand, price range, in-stock, and (Advanced + specific category) the per-spec filters. Move per-spec filter state up from SpecTable into Browse and pass `filters`/`setFilters` down so the sidebar owns them; SpecTable keeps only sorting and renders rows from `items` (already filtered). Provide `columnFilters` applied in Browse's `filteredComponents` memo using `specColumns` helpers.
- [ ] Build + tests: `npm run build`, `npx vitest run`. Commit.
